# 知炼 EchoMind 产品文档

版本：PRD v2.0
日期：2026-09-11
赛道：知乎黑客松「知识炼金场：学习工具与知识生产」

## 1. 产品定位

知炼 EchoMind 是知乎问题页内的一个**原生「凝炼模式」**。用户在阅读知乎回答时，一键从「看原文」切换到「看凝炼」，系统把冗长的回答实时炼成：一句话结论、经验卡片、避坑清单、行动步骤和自测题。

一句话：**用户打开知乎问题页，凝炼模式把五千字长文压成 30 秒能看懂、能照做的干货。**

产品主张：知炼帮知乎把「高质量内容消费」升级为「可验证的学习转化」。

### 形态说明（重要变化）

- 不做浏览器插件，也不做独立工作台。
- 定位为知乎 App 内的原生功能，用 HTML 高保真模拟原生问题页来演示。
- 评委看到的是「如果知乎内置凝炼模式，用户在问题页会得到什么」。

## 2. 目标用户

核心用户是有明确学习或成长目标、但没有体系化方法的人。

典型用户包括大学生、职场新人和自我提升用户。他们常常收藏了很多回答，也知道自己想提升什么，却卡在三个点：**内容太长读不动、不知道哪些可信、看完不知道下一步做什么**。

## 3. 核心痛点

知乎内容的价值常埋在五千字长文里，且真实经验没有被凝炼成干货。用户的问题不是看不到答案，而是：

- **冗长**：一个回答讲自己的经历，五千字以上，干货藏在叙事里，要读者自己淘。
- **不凝炼**：看完不知道哪些是可执行的步骤、哪些是铺垫。
- **难辨真假**：身份标签造假、软广混在经验里，不知道该信谁。
- **看完不落地**：收藏了就是学了，没有行动和验证。

## 4. 差异化

知炼的差异化是「把知乎的回答炼成密度高、可信、可执行的干货」，核心是「凝炼五件套」：

1. **干货密度预评分 + 时间成本标签**（阅读前）：还没读就知道「这篇值不值得读」。
2. **凝炼视图**（阅读中）：一屏见结论、见步骤、见踩坑。
3. **避坑清单**（阅读中）：失败经验单独提取，比成功故事更值钱。
4. **干货可信度分层 + 证据锚点**（信任）：亲历者 vs 转述者，每条干货可跳回原文查证。
5. **共识经验合并**（跨回答）：十条回答里重复验证的经验去重合并成一条高可信结论。

## 5. 使用场景

演示形态是「模拟知乎 App 问题页 + 凝炼模式」。

用户打开模拟问题页，看到问题标题、回答列表和一条五千字的长回答。打开「凝炼模式」后，长回答被替换为凝炼视图。普通用户主要看到凝炼结果；评委可以展开 trace 查看 Agent 协作过程。

## 6. 数据输入

MVP 使用模拟知乎开放接口数据。字段设计如下：

| 字段 | 用途 |
|---|---|
| `question_id` | 唯一定位问题 |
| `question_title` | 判断主题和学习意图 |
| `answer_id` | 绑定来源和引用 |
| `answer_content` | 提炼经验、行动和自测题（含冗长原文） |
| `author_tag` | 保留答主身份与适用范围 |
| `author_role` | 亲历者 / 从业者 / 转述者的可信度判断依据 |
| `voteup_count` | 高赞回答质量信号 |
| `comment_summary` | 提供反例提醒、质疑和适用边界 |

MVP 不接真实知乎账号，不抓取真实页面。后续接入知乎开放接口时，只替换 adapter，不改变核心 Agent 链路。

## 7. 用户可见结果

凝炼模式下，普通用户默认看到：

- **凝炼模式开关**：原文 / 凝炼一键切换。
- **干货密度预评分 + 时间成本标签**：如「5000 字 · 干货率 18% · 读原文 12 分钟 / 看凝炼 30 秒」。
- **一句话 TL;DR**：这篇到底说了啥。
- **经验卡片**：按「背景—做法—结果—适用条件—风险」拆成的原子结构。
- **避坑清单**：所有「不要做 / 我踩过的坑」单独成列。
- **步骤级行动清单**：可照做的 SOP，每条带完成标准、预计时间、来源和置信度。
- **干货可信度分层**：标注亲历者具体做法 / 从业者转述 / 泛泛观点，并据此排序。
- **证据锚点**：每条结论可跳回原文段落，带作者标签和赞同数。
- **自测题 + 错题复习卡片**：默认 3 题，答错后针对错因补 1 张卡片。

## 8. Agent 设计

普通用户不直接看 Agent 过程，评委 trace 展示完整链路。

| Agent | 职责 | 用户侧体现 |
|---|---|---|
| DensityScorer | 计算干货率、阅读时间与凝炼后时间 | 干货密度预评分 + 时间成本标签 |
| Distiller | 生成一句话 TL;DR、经验原子卡片、避坑清单 | 凝炼视图核心内容 |
| ConsensusMerger | 跨回答去重，合并高赞验证的共识经验 | 共识经验 |
| CredibilityTagger | 判断亲历者/转述者，识别软广，标注可信度 | 干货可信度分层 |
| ActionCoach | 把经验转成步骤级行动清单 | 步骤级行动清单 |
| Quiz | 生成 3 道自测题并识别错因 | 自测题 |
| Review | 绑定证据锚点、来源、不确定点 | 证据锚点与 trace |

## 9. 自测反馈闭环

用户完成 3 道自测题后，系统判断错因：

- 概念理解题答错：补一张概念复习卡片。
- 场景判断题答错：补一张适用条件卡片。
- 行动排序题答错：补一张步骤复盘卡片。

MVP 只补卡片，不大幅重排完整学习计划。这样闭环足够清楚，演示也稳定。

## 10. MVP 范围

MVP-01 原生问题页 + 凝炼模式切换

- 模拟知乎 App 问题页（问题标题、回答列表、一条五千字长回答、评论区）。
- 提供原文 / 凝炼一键切换。
- 打开凝炼模式后自动触发分析。

MVP-02 干货密度预评分 + 时间成本标签

- 每条回答标出干货率、预计阅读时间、凝炼后时间。
- 长回答在列表里就显示「值不值得读」的信号。

MVP-03 凝炼视图

- 输出一句话 TL;DR、经验卡片、避坑清单。
- 凝炼视图为首屏主内容，一屏见结论。

MVP-04 干货可信度分层 + 证据锚点

- 每条干货标注亲历者 / 从业者 / 转述者，并据此排序。
- 每条结论可跳回原文段落，展示作者标签和赞同数。

MVP-05 共识经验合并

- 多条回答里重复出现的经验去重合并，标注「被 N 个高赞回答验证过」。

MVP-06 步骤级行动清单

- 输出可照做的步骤清单，每条带动作、完成标准、预计时间、来源和置信度。
- 数量依据具体情况动态决定，通常 3 到 5 条。

MVP-07 自测 + 错题卡片

- 默认生成 3 道自测题。
- 用户答错后生成 1 张针对错因的复习卡片。

MVP-08 评委 trace

- 普通用户只看凝炼结果。
- 评委展开 trace 查看 DensityScorer、Distiller、ConsensusMerger、CredibilityTagger、ActionCoach、Quiz、Review 的中间产物。
- trace 展示 source_ids、作者标签、赞同数、评论反例和不确定性。

## 11. 非目标

- 不做真实知乎登录。
- 不做浏览器插件上架。
- 不抓取真实知乎页面。
- 不承诺开放接口字段一定可用。
- 不做完整学习管理系统。
- 不做大型知识图谱。
- 不把评论区当成事实来源，只作为反例或边界信号。

## 12. Demo 脚本

1. 打开模拟知乎问题页：如何从零转行做 AI 产品经理？
2. 页面里有一条五千字的长回答，答主标签「大厂 AI 产品经理」，赞同 324。
3. 用户打开「凝炼模式」，长回答被替换为凝炼视图，先看到一句话结论和干货率。
4. 凝炼视图展示经验卡片、避坑清单、步骤级行动清单，每条带可信度分层和证据锚点。
5. 用户点开评论区反例，看到「我照做但翻车了，因为……」的边界提醒。
6. 用户完成 3 道自测题，其中 1 道答错，系统针对错因补 1 张复习卡片。
7. 评委打开 trace，看到各 Agent 如何评分、提炼、合并、分层、生成行动、检查证据。

高光时刻：五千字长文一键变成一屏干货，用户答错后不是只显示分数，而是立即补一张针对错因的复习卡片。

## 13. 成功指标

演示指标：

- 3 分钟内完成「打开问题页 → 切换凝炼模式 → 看干货 → 自测 → 错题补卡 → trace 展示」。
- 评委能明显感知「冗长 → 凝炼」的转化。
- 评委能看出系统使用了知乎特征字段：作者标签、赞同数、评论反例。
- 评委能看出系统不是「总结器」，而是「密度评分 + 凝炼 + 可信度分层 + 共识合并 + 行动转化 + 自测补卡」。

产品指标：

- 用户能在 10 秒内理解「这篇值不值得读、下一步做什么」。
- 每条核心行动都有 source_ids。
- 自测默认 3 题。
- 答错后至少生成 1 张复习卡片。
- 证据不足时明确显示不确定。

技术指标：

- 本地 demo 无外部依赖可跑通。
- 数据 adapter 可替换为知乎开放接口。
- Agent trace 可复现每个步骤的输入摘要、输出摘要和来源。

## 15. 已确认决策

- 产品形态：原生 App 内的「凝炼模式」，不做插件。
- 演示形态：HTML 高保真模拟原生问题页。
- 核心产物：凝炼视图（TL;DR + 经验卡片 + 避坑清单）+ 步骤级行动清单。
- 干货密度预评分、时间成本标签、可信度分层、证据锚点、共识合并为「凝炼五件套」。
- 自测题默认 3 题，答错后针对错因补 1 张复习卡片。
- 答主身份展示为作者标签，评论区主打反例提醒。
